# Детальный промпт для Cursor AI: Создание MSX-портала для HDRezka на LG webOS

**Роль:** Старший Full-stack разработчик и эксперт по Smart TV.

**Контекст:** Необходимо создать кастомный портал для приложения "Media Station X" (MSX) на LG webOS. Цель — разработать самохостируемую (GitHub Pages) JSON-основу, которая будет служить оберткой для кинотеатра HDRezka. Особое внимание уделить специфике работы с пультом дистанционного управления LG Magic Remote и стандартным D-pad.

## Технические спецификации:

*   **Целевая платформа:** Media Station X (MSX) на LG webOS. Требуется полная поддержка навигации с пульта ДУ.
*   **Основной файл:** `index.json` (точка входа для MSX).
*   **Основная функция:** Рабочая ссылка/приложение для HDRezka с корректной навигацией.

## Требования к задаче:

### 1. Структура JSON для MSX:

Создать валидную JSON-структуру для MSX, включающую `name`, `version` и `items`. Элемент "HDRezka" должен использовать `type: "link"`, но с учетом специфики навигации. Стандартные ссылки MSX часто теряют фокус на обычных веб-сайтах. Предложить решение для этой проблемы, возможно, через:

*   Использование `HTML5X Plugin` для встраивания веб-контента HDRezka, что позволит MSX лучше контролировать отображение и навигацию [1].
*   Использование `Interaction Plugin` для перехвата событий пульта ДУ и их трансляции в веб-страницу, если прямое встраивание не обеспечивает нужной функциональности [2].
*   Предложить использование TV-friendly зеркала или специализированной версии сайта HDRezka, если таковые существуют и решают проблему фокуса.

### 2. Фикс навигации для пульта ДУ:

Разработать небольшой JavaScript-сниппет (или подробно объяснить, как его интегрировать в качестве "User Script" или "Plugin" в MSX), который будет маппировать кнопки пульта ДУ (VK_UP, VK_DOWN, VK_LEFT, VK_RIGHT, VK_ENTER, VK_BACK) на стандартные браузерные события. Это критически важно для LG Magic Remote (как для указателя, так и для D-pad) и стандартных пультов. Учесть, что `Interaction Plugin` может быть использован для обработки событий [2].

### 3. Proxy/Parser для HDRezka (продвинутый уровень):

Предоставить Python (Flask) или Node.js скрипт, который может быть запущен на сервере для "скрапинга" HDRezka. Скрипт должен возвращать чистый FXML (если MSX поддерживает его для отображения структурированных данных, хотя основным форматом является JSON [1]) или, что более предпочтительно, JSON-список фильмов. Это позволит отображать постеры, описания и другую метаинформацию непосредственно в интерфейсе MSX без необходимости открывать полный веб-сайт HDRezka. В JSON-списке должны быть поля, совместимые с `Content API` MSX (например, `title`, `image`, `description`, `action` для воспроизведения) [1].

### 4. Развертывание на GitHub Pages:

Предоставить пошаговое руководство по структурированию репозитория GitHub, чтобы MSX мог корректно читать `index.json`. Убедиться, что GitHub Pages настроен для поддержки CORS, так как это необходимо для MSX [1].

## Желаемый результат:

*   Полный код `index.json`.
*   Руководство в стиле README по обновлению зеркал/ссылок HDRezka.
*   Скрипт для простого парсера "Rezka-to-MSX" (Python/Flask или Node.js), если это возможно.

## Советы по использованию в Cursor:

*   **Файловая структура:** Попросить Cursor создать два файла: `index.json` (основной конфиг) и `rezka_parser.py` (или `.js`, в зависимости от выбранного языка для парсера).
*   **Уточнение про Magic Remote:** Обязательно указать: "Make sure the navigation works with LG Magic Remote pointer and D-pad arrows specifically."
*   **Зеркала:** Попросить добавить переменную для "Base URL" в парсере, чтобы можно было быстро менять заблокированные домены Rezka в одном месте.
